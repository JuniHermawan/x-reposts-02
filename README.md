Quote posts for make.fun's newest X posts: three quote posts, each answering a different @makefunai post with its own words, @makefunai and the play code in the text. Ranking is by each post's reposts, quotes and likes after the deadline; top 50 share $500 USDC.

`POSTS.json` holds the posts' addresses (placeholders until the posts go live — see `POSTS.txt` for the exact post texts and which pool post each quotes).

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/POSTS.json` and `out/POSTS.txt`, where the make.fun gate reads them.
